Chrome 経由 GPS ブリッジ (Even Hub WebView の代替)

Even Hub WebView は GPS を遮断するので、別の Chrome タブで companion.html を開き GPS を読ませ、ntfy.sh 経由でこちらに中継する仕組み。

Android の Chrome で https://nonimon3.github.io/speed-meter/companion.html を開き、同じコードで開始してください。

起動中…

Simulator では GPS が使えないので「Mock: ON」にすると適当な速度が流れます。
URL に ?mock=1 を付けると自動で Mock 起動。?mock=1&profile=highway でプロファイル指定も可。
タップ = 単位切替 (km/h ⇔ mph) / ダブルタップ = 終了 / Mock 中はスクロールでプロファイル切替
